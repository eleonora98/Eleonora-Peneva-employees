<h2 align="center">
Pair of employees who have worked together
</h2>

**A task for comparing and finding the pairs of employees that have been working on a project for the longest period of time.**

1. Employees and projects data are imported through a .CSV file from the user through the UI.
2. A set of supported input date formats.
3. DateTo can be NULL, equivalent to today
4. Results are shown in a datagrid.

Technologies used:
- Java + Spring Boot
- Angular
